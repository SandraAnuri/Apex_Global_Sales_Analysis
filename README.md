# Apex Global Sales Performance Analysis
This repository contains my end-to-end data analysis project for Apex Global. I took this project through the full analytics pipeline: cleaning raw data in Google Sheets, writing structured SQL queries to analyze key metrics, and building an interactive Power BI dashboard to present insights clearly.
---
## Project Structure and Files
The files in this repository follow the exact sequence of my analysis:

* **01_Data_Cleaning_and_Pivot_Table.xlsx**
Cleaned raw sales data, fixed formatting issues, handled missing values and duplicates, and created initial pivot tables to inspect sales by region and product category.

* **02_Sales_Analysis_Queries.sql**
SQL queries used to calculate core business metrics, including total revenue, average order value, top sales reps, and category breakdowns.

* **03_Apex_Global_pbi_Sales_Dashboard_2026.pbix**
Power BI dashboard utilizing calculated metrics and data aggregations, containing a dynamic data model and interactive visuals to display key performance indicators across two executive report pages.

* **04_Apex_Global_tableau_Sales_Dashboard_2026.twbx**
Interactive executive dashboard built in Tableau Desktop featuring dynamic region slicers, multi-sheet cross-filtering, and customized tooltips to deliver real-time sales visibility across regions and product categories.
* [Live Tableau Dashboard](https://public.tableau.com/app/profile/sandra.egwuabor/viz/ApexGlobalSalesAnalysis/ApexGlobalSalesDashboard?publish=yes)
---
## Key Business Takeaways
* **Top Revenue Drivers:** A few sales representatives and core regions account for most of the overall margin.
* **Product Mix:** High-volume items do not always yield the highest profit margins; optimizing product pricing could improve profitability.
